# 公司分析 Skill

## 适用场景

- 用户要求分析某家公司或上市公司；
- 需要将公司档案、财务数据与行业信息整合为一份简报；
- 作为行业研究报告的素材收集步骤。

## 工作流

1. **明确对象**
   - 确认公司名称、股票代码（如有）、分析时间范围。
   - 若信息不足，先向用户询问，不要猜测。

2. **获取公司档案**
   - 调用 `get_company_profile` 获取公司全称、成立时间、总部、员工规模、
     核心业务等。

3. **获取财务概况**
   - 调用 `database_search` 获取营收、净利润、成本、研发投入、现金储备。
   - 当前为 Mock 数据，必须在输出中标注“模拟数据”。

4. **补充行业与新闻**
   - 仅在关键信息缺失时使用 `web_search`，并控制调用次数。
   - 记录来源与时间，禁止把搜索摘要当作唯一证据。

5. **结构化输出**
   - 公司概况
   - 业务模式与收入结构
   - 财务表现（注明数据口径与来源）
   - 竞争优势与风险
   - 结论与待验证问题

## 输出要求

- 使用 Markdown 标题层级；
- 区分事实、推测与观点；
- 不构成投资建议；
- 需要保存时写入 `/workspace/company_analysis.md`，并验证文件存在。

## 可用工具

- `get_company_profile`
- `database_search`
- `web_search`（需人工审核）
- `read_file` / `write_file`
